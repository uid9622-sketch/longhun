# Paper standard operating procedure

1. Register the research unit before adding manuscript claims.
2. Keep each paper and version isolated; never overwrite another paper's artifacts.
3. Preserve original sources, formula changes, literature mappings, and adverse evidence.
4. Use explicit states: `DRAFT`, `MAJOR_REVISION`, `CONDITIONAL_PASS`, `PASSED`, and
   `RELEASED`. A state applies only to its recorded scope.
5. Keep experiments `NOT_RUN` until real execution evidence exists.
6. Do not confuse formula checks, citation verification, rendering checks, or self-review
   with whole-paper acceptance.
7. Formal publication follows the release protocol; initializing structure is not a
   release.
