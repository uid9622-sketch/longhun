# Research protocols

These protocols govern repository procedure; they are not additional license
restrictions. Repository content is licensed under CC BY 4.0 as stated in `LICENSE` and
`LICENSE-NOTICE.md`.

- `paper_sop/`: research-unit and version workflow.
- `review_protocol/`: review independence, scope, and append-only records.
- `release_protocol/`: immutable releases, tags, hashes, backups, and signatures.

A protocol file does not prove that the procedure was executed.
