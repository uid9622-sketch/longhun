# Review protocol

Every review record identifies its target version, reviewer, date, scope, evidence, and
limitations. Reports are append-only; corrections create a new record rather than
overwriting the original.

Self-review is labeled `SELF_REVIEW` and cannot satisfy an independent-review
requirement. `UNVERIFIED` remains in effect when independent evidence is absent.
Reviews must preserve adverse findings and must not manufacture experiments, statistical
results, or reviewer endorsements.
