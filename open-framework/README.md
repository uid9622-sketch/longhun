## 这个仓库是什么

龍魂系统的**公开层**。这里只有三类东西：

1. **已公开的算法** —— 数学定义完整给出，可复算、可审计（零黑箱承诺）
2. **工程交付标准** —— 任何模块怎么从草稿走到交付，四阶段一条线
3. **治理原则** —— 这套系统为谁服务、红线在哪、怎么接受监督

核心代码与私有资产不在这里。这里的一切都可以验证：**每个文件在 `MANIFEST.sha256` 里有 SHA-256 指纹，改一个字都对不上。**
